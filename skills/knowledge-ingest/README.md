# knowledge-ingest

Agent Skill for automated knowledge ingestion. Bridges voice, text, and web content into your Obsidian vault via local pipeline processing.

## Capabilities

- **Voice-to-Note**: Transcribe audio via local Whisper and convert to structured Markdown
- **Auto-Frontmatter**: Generate YAML metadata (tags, dates, categories, summaries) via local LLM
- **Web Extraction**: Pull clean Markdown from URLs (integrates with defuddle)
- **Batch Processing**: Monitor directories and auto-process incoming files
- **Privacy-First**: 100% offline capable using local Whisper + Open WebUI

## Installation

### Prerequisites

- Python 3.9+
- `openai-whisper` (local)
- Open WebUI running locally (optional, for LLM enhancement)

### Setup

```bash
# 1. Install Python dependencies
pip install openai-whisper pyyaml requests

# 2. Configure your vault path
cp config/workflow.yaml.example config/workflow.yaml
# Edit workflow.yaml and set your vault_path

# 3. Verify Whisper model download
whisper --model medium --help
```

## Tools

### `ingest_voice`

Transcribe audio files and create Inbox notes.

**Usage:**
```
/ingest_voice --file meeting.m4a --title "Team Standup"
```

**Parameters:**
- `file` (required): Path to audio file
- `title` (optional): Note title, defaults to filename
- `language` (optional): Whisper language code, defaults to "zh"
- `model` (optional): Whisper model size (tiny/base/small/medium/large), defaults to "medium"

### `ingest_text`

Import raw text files with auto-structured formatting.

**Usage:**
```
/ingest_text --file draft.txt --title "Article Ideas" --tags idea,writing
```

### `ingest_web`

Extract content from URLs into Markdown.

**Usage:**
```
/ingest_web --url https://example.com/article --title "Reference Notes"
```

### `batch_ingest`

Monitor a directory and process all supported files.

**Usage:**
```
/batch_ingest --watch-dir ~/Dropbox/Inbox --auto-archive true
```

### `generate_frontmatter`

Analyze note content and suggest optimal YAML frontmatter.

**Usage:**
```
/generate_frontmatter --file _Inbox/2026-07/untitled.md
```

## Workflow Integration

This skill outputs to `_Inbox/{YYYY-MM}/` with status: `inbox`. 

**Next step:** Use `knowledge-refine` skill to process into permanent knowledge.

## Directory Structure

```
VAULT/
├── _Inbox/
│   └── 2026-07/
│       └── 20260722-meeting.md     ← Generated by this skill
├── _Processing/                     ← Handoff to knowledge-refine
└── Knowledge/                       ← Final destination
```

## Configuration

See `config/workflow.yaml` for:
- Vault path
- Inbox naming conventions
- Default Whisper model
- Open WebUI endpoint
- Auto-tagging rules

## Pipeline Architecture

```
Audio/Text/Web ──→ [Whisper/Parser] ──→ [Local LLM*] ──→ [Formatter] ──→ _Inbox/
                                      * Optional enhancement
```

All processing stays local unless you configure remote LLM endpoints.
